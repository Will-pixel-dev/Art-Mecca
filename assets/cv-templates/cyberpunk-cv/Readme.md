# 💻 Cyberpunk CV Template

A dark, neon-drenched CV with glitch effects and holographic accents.

## ✨ Features

- Fully responsive
- Dark mode with neon accents
- Glassmorphism UI
- Professional layout
- Easy to customize

## 🔧 How to Customize

1. **Change the name** — Edit "ARTIST NAME" in the header
2. **Update contact info** — Edit the contact bar (email, phone, location, website)
3. **Add your skills** — Edit the skills section with your own skills and levels
4. **Add your experience** — Edit the experience section with your own roles and companies
5. **Add your education** — Edit the education section
6. **Add your exhibitions** — Edit the exhibitions section
7. **Update the profile** — Edit the profile paragraph
8. **Update the portfolio link** — Change the `href` to your actual portfolio URL
