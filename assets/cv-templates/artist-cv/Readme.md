# 🎨 Artist CV Template

Designed specifically for artists and illustrators with sections for exhibitions, commissions, and portfolio links.

## ✨ Features

- Fully responsive
- Dark mode with cyan accents
- Artist-focused sections
- Professional layout
- Easy to customize

## 🔧 How to Customize

1. **Change the name** — Edit "ARTIST NAME" in the header
2. **Update contact info** — Edit the contact bar
3. **Add your skills** — Edit the skills section
4. **Add your experience** — Edit the experience section
5. **Add your education** — Edit the education section
6. **Add your exhibitions** — Edit the exhibitions section
7. **Add your commissions** — Edit the commissions section
8. **Update the profile** — Edit the profile paragraph
9. **Update the portfolio link** — Change the `href` to your actual portfolio URL
