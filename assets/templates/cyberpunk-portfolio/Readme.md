# 🎨 Cyberpunk Neon Portfolio

A dark, neon-drenched portfolio template with glitch effects and holographic accents.

## ✨ Features

- Fully responsive
- Dark mode with neon accents
- Glassmorphism UI
- Scanlines and noise effects
- Easy to customize

## 🔧 How to Customize

1. **Change the name** — Edit "Artist Name" in the header and hero
2. **Add your artwork** — Replace the placeholder `<div class="placeholder">` with your images
3. **Update social links** — Change the `href` in the footer social icons
4. **Customize colors** — Edit the `:root` CSS variables
