# 🎨 Minimalist Clean Portfolio

A light, clean, and elegant portfolio template that puts your artwork front and center.

## ✨ Features

- Fully responsive
- Light mode with clean typography
- Elegant sans-serif + serif font pairing
- Minimalist design
- Easy to customize

## 🔧 How to Customize

1. **Change the name** — Edit "Artist Name" in the header and hero
2. **Add your artwork** — Replace the placeholder `<div class="placeholder">` with your images
3. **Update social links** — Change the `href` in the footer social icons
4. **Customize colors** — Edit the `:root` CSS variables
